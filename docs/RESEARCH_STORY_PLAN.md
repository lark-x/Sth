# Sth 资料研究与故事创作计划

目标是让作者或助手从一句指令完成有出处的故事，同时保留打开日记即可记录、独立写场景的自由。网页、MCP、Hermes 通过同一份操作目录读写版本化资源。此计划在既有四阶段工作区上继续开发。

## 能力归属与扩展

| 后端模块 | 它负责保存或决定什么 | 作者从哪里开始 |
| --- | --- | --- |
| 资料 `sources` | 外部检索和读回、归档原文与版本、摘录坐标、支持或反驳某个判断的依据。新增资料源在这里实现提供方协议。 | 资料。选中原文可以查看引用或保存判断。 |
| 个人与作品 `library` | 作品身份、日记、角色卡，以及作者明确采纳的角色条目。日记引用资料原文，角色条目可引用故事稿件。 | 日记、角色，或创作里的作品。 |
| 故事 `story` | 场景、稿件、章节、事件及已知先后、讲述顺序、视角、IF 分歧与分支中的角色状态。 | 创作。改讲述顺序沿用事件，改变角色经历在分支内接续。 |
| 文字生成 `generation` | 模板、要求、方案、文字委托与批次。本次采用的版本、实际提示词、各段出处和生成结果一起保存。 | 从创作发起，在生成记录中打开提示词组成，后台进度从任务查看。 |
| 素材 `assets` | 图像、音频等上传原件及读取，角色模块决定素材在卡片中的顺序和含义。 | 使用素材的角色条目。 |
| 媒体任务 `jobs` | 构图选择、媒体任务的提交与恢复、生成产物，以及按时间汇总各类任务的只读列表。 | 创作里选构图，任务里查进度并打开具体成果。 |

二次开发先确定哪个模块拥有新数据、版本和写操作。比如「依据三个场景提炼一个人的说话方式」可组合读稿、选择引文、采纳角色条目三个现有动作；「接另一家资料库」只需接入资料提供方。跨模块保存资源 ID 与必要的版本或选段。网页和 AI 都通过同一操作契约执行，日常入口按作者手头的事安排。新增独立模块前，先用一个当前模块组合无法表达的真实场景说明边界。[操作注册](../src/workspace.ts) · [前后端契约](FRONTEND_BACKEND.md) · [资料提供方](RESEARCH_PROVIDERS.md)

## 一、让每个判断能回到原文

资料负责原文、出处、外部文档身份、版本和摘录位置。让助手搜索资料、读上下文、选择需要的内容归档；外部提供方失联时已归档版本仍可读。保留旧摘录格式，为新引用记录确切的位置，遇到两处相同原句时能选择其中一处。可复用的解读保存为有版本的判断，支持依据、反证和适用范围。查原文可找到采用它的判断，旧稿可打开当时的证据。

## 二、用证据编排故事，从故事提炼角色

故事模块保存事件、发生顺序、视角和分支状态。只知道前后时可以直接建立关系，未确定的先后维持开放。讲述顺序属于稿件或场景的编排，可引用相同事件形成两个版本。改变经历可从选中版本另开 IF；分支后的人物状态、所知事件和续写位置可以跨会话读回。角色模块接受从某一段原稿或判断采纳的条目，支持保留引用与既有图像、音频、文本。临时解读或分支中的角色变化只有在作者要求时才进入共用角色卡。生成模块固定实际采用的资料、判断、事件、人物和视角，并让用户从结果打开本次 Sth 提示词及其来源。

## 三、用五个入口完成日常创作

日记、创作、角色、资料、任务作为主入口。创作页直接进入独立场景、作品、模板和写作要求，任务页统一找文字和媒体的进度并返回成果。连接归设置。原有链接继续直达资源。研究与编排从资料或场景上下文进入，正文能查看依据、提炼条目、另开 IF；生成记录和提示词可单独打开。以窄屏和桌面浏览器验证导航、输入、链接与重新加载。

## 四、验收与发布

| 场景 | 通过条件 |
| --- | --- |
| 温妮莎的两种讲述 | 搜索、读取并归档两份资料；区分原文与推断。相同事件可按时间或人物视角讲述；当事人尚未知晓的材料不出现在其受限输入里。能从稿件或提示词回到相应版本与摘录。 |
| 从原稿提炼角色 | 选择角色的一句台词和一项推断，只采纳指定内容，保留原文位置。反复提交相同步骤不会新增两个条目；角色并发编辑时保留其他改动。 |
| 继续没搭上船的 RP | 能找到前次分支状态、继续写和跨入口读回。改讲法沿用原事件，改经历在 IF 里操作。检查两边提示词及历史版本。 |
| 一句话记北港日记 | 空工作区无需预建作品。将资料十点改成九点后，原日记仍可查到十点，新稿可选九点。 |

验证范围包括同文多处、旧版 SQLite 升级及恢复、上游断开和结果未知、重复投递、并发修订、旧链接、文字与媒体任务、真实 Hermes 模型通过 MCP 写入和网页按 ID 读回。将可自动重复的检查与渠道实测证据分别记入验收记录。

实现沿用六个领域模块和共享事务操作。外部请求在事务外执行，域内变更与回执一并提交。参考现有开源调研中的 Logseq 段落反向链接、ink 分支和 Langfuse 提示词版本做法。保留当前预览数据并在升级前备份，在独立 Sth 工程和既有 9322 预览验收。

2026-11-24 四个阶段已在 9322 交付。自动回归、数据升级、真实普通聊天和受限视角的可复核结果见[验收记录](ACCEPTANCE.md)、[一句话研究日记](RESEARCH_CHAT.md)和[双视角模型实测](RESEARCH_LIVE.md)。
