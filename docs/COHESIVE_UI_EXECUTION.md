# 全站视觉与交互重设计

用户于 2026-11-28 批准实施。基线 `5a7fff4`，开发分支 `feat/cohesive-writing-ui`。本文件记录本轮范围、所有权、证据和未完成项；设计规范以 `DESIGN.md` 为准，业务契约仍以 `frontend/CONTRACT.md` 和领域实现为准。

## 目标与边界

Ulysses 是主要界面参考，iA Writer 提供正文节奏，Novelcrafter 提供场景上下文组织，Outline 提供 Web 控件一致性参考。采用 Vue/Reka/Lucide 和本地组件，不引入第二套主题。浅色全站、手机逐屏导航、目的明确的动效；现有可达旧页面也计入验收。

不得混淆选中/最新/采用、本地恢复/已保存/结果未知、历史依据/可用资料/下一稿准备。保留精确修订与选段链接、明确采用、历史编辑新建修订、回执重试、焦点和滚动恢复。无数据库格式和外部接口迁移。浏览器自动化验收，不使用 Computer Use；真机 iOS/WKWebView 后续单独验收。

## 共享设计接口（实施约定）

颜色权威仍在 `web/assets/notebook.css`：白色纸面、轻灰资料库、近白列表、墨色主文字、可读次文字。新增 `--surface-subtle`、`--surface-hover`、`--field-border`、`--focus-ring`、`--radius-control`、`--radius-panel`、`--shadow-popover`、`--motion-fast`、`--motion-normal`、`--motion-panel`、`--ease-out`，由主代理持有。现有颜色变量继续兼容。间距以 4/8/12/16/24/32/48px 为起点，正文保留 18px/1.8 与可读行宽。桌面主控件约 36–40px，手机/粗指针触区至少 44px。

`frontend/ui/Button.vue` 保留 default/outline/secondary/ghost 与 default/sm/icon，增加 danger 变体和 loading 展示。业务决定 disabled/loading；组件只渲染状态。链接可通过 as="a" 保留原生语义。字段继续原生 input/select/textarea，共享 `.ui-field`/`.ui-input`/`.ui-field-note`/`.ui-field-error` 样式。各域可保留定位类，但移除重复的颜色、尺寸与状态定义。图标沿用 AppIcon，避免 Unicode 代替图标。

菜单从触发点展开；依据面板进入/退出；手机导航方向对应前进返回；保存状态跟随真实回执。逻辑状态立即生效，退场仅影响展示生命周期。业务不依赖 animationend；减少动态、快速反向、卸载和跨断点必须清理。正文不做持续动画。
