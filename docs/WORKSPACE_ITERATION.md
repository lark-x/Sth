# Sth 创作工作区迭代计划

更新于 2026-11-27。Sth 服务于用自然语言写日记、整理原文、推敲长篇的个人作者。作者可以在习惯的助手里交代想法，在网页上读稿、修订和选稿。换到另一个助手后，作品、出处、采用的版本和仍待商量的事都能接着用。

最小体验是一篇独立日记。复杂体验从一段原文或一个角色开始，经讨论产生不同讲法，作者选定一稿后编入章节。改变事件走向时另开 IF。两种体验共用作品、日记、角色、资料与故事模块，以及同一组可发现的业务操作。日常写作沿用当前对话的模型，点名方案或委托批量任务时才启动对应供应商。

## 当前起点

私有仓库 `lark-x/Sth` 的默认分支为 `main`，起点为 `ec1f1e4`。第一轮开发分支为 `feat/agent-workspace-onboarding`。本机作者工作区在 9322，已有带出处的日记、两种视角的成稿、IF 接续位置和场景插画。它们是升级与改版的真实回归样本。[原始四阶段计划](AI_NATIVE_ROADMAP.md) · [原文到故事的立项设计](RESEARCH_STORY_PLAN.md) · [现有作品与验收记录](ACCEPTANCE.md)

## 六阶段交付

| 阶段 | 作者得到什么 | 交付与验收 |
| --- | --- | --- |
| 1 · 建立基线 | 当前版本有可恢复的远程起点 | 在私有远程核对 `main`、当前提交与默认分支。干净克隆独立装依赖，跑类型、核心、适配器及桌面和窄屏浏览器回归。后续改动在开发分支独立验证。 |
| 2 · 安装自己的工作区 | Hermes 用户安装插件后可以创建个人工作区，也可接入已有工作区 | 提供可复制的本地安装方式、数据位置、启动、重启、状态和配对。首次安装验证空库，重复启动验证原数据，两个用户的连接可以分别撤销。用独立 profile 验证真实 Hermes 安装、工具发现和写入。 |
| 3 · 跨端写完第一篇 | 用 Hermes 记下想法，在手机上改一句，换 Codex 仍能找到初稿和新稿 | 独立宿主绑定同一服务，真实 Hermes 写入，390px 网页从可见编辑入口保存，全新 Codex 会话按同一 ID 实际读取第一版和最新版。逐一核对正文、版本和回执。Antigravity 并行接入，另验真实客户端安装、发现、写入及新会话读回。 |
| 4 · 重做桌面与手机工作区 | 打开首页能继续上次的稿子；桌面适合查阅对照，手机适合速记、读稿和改稿 | Vue 3 按域迁移首页、日记、作品与场景、角色与资料、任务与媒体及设置。保留旧链接、精确版本、前进后退。桌面借鉴 Ulysses 的书库与正文分区、iA Writer 的阅读行宽、Novelcrafter 的场景上下文。手机逐屏展开，保留来源与返回位置。逐域复测旧路径、草稿恢复、冲突以及窄屏排版。 |
| 5 · 让下一位助手能接手续写 | 作者能从角色或引文提出两种讲法、选稿入章、另开 IF，下次回来能查明上次定了什么 | `story` 按作品和分支记录带版本的提案、待决问题、作者确认的决定及依据。问题结案指向当时确认的决定版本。已有 `checkpoint` 记录续写位置，`scene.adopt` 记录选稿，来源固定到原文版本。验收网页确认、新会话接续、改判后仍能重建旧版上下文，检查主线与 IF 的隔离。 |
| 6 · 升级与移动交付 | 现有作者能保留作品和媒体升级，手机可从助手返回同一份稿件 | 原卷一致性快照、隔离副本升级与恢复、核对历史作品和媒体字节，验证后发布至本机 9322。区分窄屏浏览器、真实 iPhone Safari 的输入保存与重新打开、未来 WKWebView 嵌入的导航/鉴权/文件选择验证。现阶段交付移动网页与嵌入契约，独立 iOS App 的发布属于后续产品范围。 |

阶段顺序按作者体验验收。第一条跨宿主日记可以先用现有网页跑通，Vue 每迁一域再跑对应路径。故事决定与 IF 的后端用例可提前并行，以历史版本读回为依据确定网页交互。宿主缺少账号或真机时单列具体条件，继续推进可执行的工作。

## 决策与分工

主代理负责产品计划、写入范围、集成及独立验证。遇到涉及产品定位、持久化语义、宿主能力差异或整体迁移策略的实质决策，先由原生 `gpt-6.2-sol`（xhigh）与 `chatflowsai/gpt-6.2-astra`（xhigh）讨论，再由主代理记录并执行综合推荐。实现分派给 `xingchi/gpt-6.1-sol`（xhigh），同时工作最多 8 个子智能体，讨论席计入上限。验证使用 CLI、HTTP、独立数据库与自动化浏览器。

| 已采纳的推荐 | 对产品的影响 | 如何查验 |
| --- | --- | --- |
| 先交付一条真实跨宿主日记，再按域替换 Vue 界面 | 第一批作者即可验证安装和跨端接续，迁移期间老作品仍有入口 | 同一日记 ID 的两个版本，独立配对、手机网页操作与新会话实际调用 |
| 将作者决定、待决问题和事实分别保存和呈现 | 助手可以提出可能性；作者明确确认后，下位助手才将其当作已定事项 | IF 改判后指定旧版组稿，检查原先决定及原文版本 |
| Antigravity 和 iOS 各有独立的验收结果 | 第三宿主可与界面开发并行，移动网页与原生容器可按设备条件分别验收 | 真实客户端写入及重开读回；分别记录 iPhone Safari 和 WKWebView 的实测环境 |
