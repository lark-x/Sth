# 手机网页与 iOS 容器接入

Sth 网页是手机上的创作入口。未来的 iOS App 可在 `WKWebView` 中装载同一作者工作区。服务端 SQLite 保存作品和修订，域名决定打开哪个工作区。当前交付包含 Vue 移动布局、可直接打开的资源链接和浏览器回归。

## 打开同一篇稿件

1. 在手机可以访问的 HTTPS 域名上部署工作区，将服务的 `STH_PUBLIC_ORIGIN` 设置为该来源并配置 `STH_WEB_PASSWORD`。反向代理保留 Host。Hermes 的 `STH_PERSONAL_OPERATIONS_PORTAL_ORIGIN` 使用同一入口。Mac 或 PC 的 `127.0.0.1` 在手机上会指向手机自身。[手机链接配置](../README.md#手机链接)
2. App 打开作者选择的工作区 URL。内部导航保留路径、查询参数及锚点。例如 `/diaries/<id>?revision=1` 是指定旧稿，`/diaries/<id>` 读取当前版本。系统返回手势先检查 `canGoBack`，有网页历史时调用 `goBack()`。外部引文交给系统浏览器。
3. 远程作者网页使用 HTTPS 和 HTTP Basic challenge。用户名是 `sth`。容器如选择代办登录，应在匹配工作区域名和服务器认证方式后请求作者凭据，并将保存决定交给作者。MCP/Hermes 的长期配对令牌仅由各自适配器使用。网页已通过同源 `/api/web` 调用共享核心，容器可直接加载服务端页面。
4. 上传角色图片、音频等文件时沿用网页的文件选择控件。页面上报告保存成功后再关闭编辑视图。容器被系统回收后，从原资源 URL 重开，已保存内容由服务读回。尚未提交的草稿恢复要按实际编辑器、系统终止与重启路径逐项检查。

## 移动验收

| 环境 | 作者操作 | 核对结果 |
| --- | --- | --- |
| WebKit 移动参数 | 从独立配对生成的日记链接进入，编辑正文并保存，关闭页面，再从旧版链接重开并查看最新版、后退 | 旧稿为第 1 版，新稿为第 2 版；配对助手再次读取的 ID 和正文一致 |
| iPhone Safari 真机 | 在手机可达域名登录，输入中文并切换输入法，横竖屏切换，展开引用，保存后退出重开 | 键盘与安全区不遮住保存操作，原稿和新稿均可回读 |
| App 的 WKWebView | 从宿主打开精确版本，完成登录，进入来源再系统返回，选择相册图片和音频，后台恢复 | 导航位置、修订号与文件预览正确，外部链接按宿主策略打开 |

WebKit 回归使用临时数据库和随机端口。安装匹配版本的 WebKit 并构建前端后运行以下命令。真实 iPhone 与实际 App 容器的验收分别记录，需填写设备、系统版本及宿主版本。

```sh
npx playwright install webkit
npm run build
node --test tests/mobile/webkit.test.mjs
```
